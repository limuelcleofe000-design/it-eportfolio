Student Profile

Limuel A. Cleofe III

BSIT 101I · Fundamentals of I.T.

Short Biography

I am a 1st-year Bachelor of Science in Information Technology (BSIT) student. I am eager to learn how technology works behind the scenes and build a strong foundation for a future career in the IT industry.

Learning Goals

Understand the basic concepts of computer hardware, software, and networking. Learn basic programming logic and problem-solving skills. Pass all my introductory IT subjects with good grades and gain confidence in using tech tools.

IT Interests

Computer Hardware: Assembling PCs, learning how parts work together, and simple troubleshooting. Web Development: Learning how websites are designed and built from scratch. Cybersecurity Basics: Understanding how to keep computers and networks safe from simple online threats.

02 · Reflection

Student Takeaways

A unified reflection area for the ideas, skills, and practical lessons developed throughout the course.

Key Lessons

Computer Fundamentals: Understanding how CPUs, RAM, and storage process and store data. Operating Systems: Learning how Windows and Linux manage system resources and files. Basic Networking: Learning how devices connect to the internet and talk to each other using IP addresses.

Challenges

Computer Hardware: Assembling PCs, learning how parts work together, and simple troubleshooting. Web Development: Learning how websites are designed and built from scratch. Cybersecurity Basics: Understanding how to keep computers and networks safe from simple online threats.

Skills Developed

Hardware Basics & Diagnostics: Identifying core computer parts and knowing how the system processes data. OS Navigation: Comfortably using and managing settings in both Windows and Linux environments. Basic Troubleshooting: Setting up desktop equipment and solving everyday hardware/software glitches.

Real-World Relevance

These fundamental lessons teach you how systems actually work under the hood. Knowing basic hardware, operating systems, and troubleshooting prepares you for entry-level IT support roles, tech setup tasks, and advanced IT courses later in your degree.
